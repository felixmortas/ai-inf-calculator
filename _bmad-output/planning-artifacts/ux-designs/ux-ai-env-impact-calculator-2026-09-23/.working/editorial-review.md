# Relecture structure et prose

Ces documents aident la personne qui réalisera l'interface à retrouver les règles visuelles et les comportements sans interpréter les maquettes. Modèle de structure : référence pour `DESIGN.md` et contrat fonctionnel pour `EXPERIENCE.md`. Mesure : 998 mots dans `DESIGN.md` et 3 330 dans `EXPERIENCE.md` avant la correction ci-dessous.

| Pass | Texte d'origine | Texte retenu | Motif |
|---|---|---|---|
| structure | Tableau « Décisions à reporter dans le produit existant » (~130 mots) | PRESERVE dans Foundation | Il relie explicitement les nouvelles décisions de Felix aux écarts d'implémentation ; le supprimer réduirait la traçabilité. |
| prose | « les URL longues se coupent dans leur conteneur » | « les URL longues reviennent à la ligne dans leur conteneur » | La première formule pouvait signifier une troncature, contraire à la lecture de l'URL de consentement. |

La formulation a été corrigée. Aucune coupe structurelle recommandée ; réduction nette : 0 mot à l'échelle des deux contrats.
