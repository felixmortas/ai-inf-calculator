# Validation UX — accessibilité

Date : 2026-09-23. Périmètre : `DESIGN.md`, `EXPERIENCE.md`, exploration « 02 · Canopée claire » dans `.working/palettes-guide-calme.html`. Le code existant sert à vérifier les risques de migration ; cette revue porte sur les spécifications, pas sur une interface finale testée au navigateur.

| Gravité | Emplacement | Constat et correction concrète |
|---|---|---|
| Élevée | `EXPERIENCE.md` — Accessibility Floor, State Patterns / prévisualisation | La prévisualisation peut contenir plusieurs longs échanges. Ne pas placer tout ce contenu dans une région `aria-live` : la récupération risque de lancer une annonce interminable. Annoncer seulement « Prévisualisation prête : N échanges, M avertissements », placer le focus sur son titre après récupération, puis laisser parcourir les échanges par titres et liste. Le code actuel utilise `aria-live="polite"` sur tout `.import-preview` (`src/ui/ConversationImport.tsx`). |
| Élevée | `EXPERIENCE.md` — consentement, prévisualisation, remplacement | Le document dit que le consentement est la seule fenêtre modale, mais le remplacement d'un fil renseigné doit aussi être confirmé. Décrire explicitement un dialogue de confirmation ou une confirmation intégrée à la page. Si dialogue : nom et description, focus initial sur l'option conservant les données, confinement du focus, Échap, restitution du focus et fond inerte. Le code actuel utilise un `alertdialog` de remplacement sans gestion de focus équivalente au consentement (`src/ui/ConversationImport.tsx`). |
| Élevée | `DESIGN.md` — Colors, Components ; maquette `.working/palettes-guide-calme.html` | Le contraste du contour `#C7D7C7` sur blanc est de **1,50:1** (1,40:1 sur `#F5F8F0`). Ce contour seul ne peut pas signaler la limite d'un champ ou d'une carte interactive. Choisir un contour d'au moins 3:1 pour les contrôles, ou leur donner un autre indice visuel de même contraste ; conserver le focus bleu distinct. Les couleurs de texte principales vérifiées passent le seuil de 4,5:1 : vert foncé sur fond 10,83:1, secondaire sur blanc 6,23:1 et blanc sur action 8,04:1. |

Après activation, déplacer le focus sur le titre de l'étape affichée, annoncer le contexte brièvement, puis garder la navigation dans l'ordre visuel. Après import confirmé, placer le focus sur le titre du fil ou le premier échange ; après annulation de remplacement, le rendre au bouton qui l'a ouvert. |
| Moyenne | `EXPERIENCE.md` — Component Patterns / Exchange card, Accessibility Floor | La carte compacte prévoit un résumé et un état, mais le nom exact du contrôle de dépliage n'est pas spécifié. Garder les valeurs de carbone et d'eau en texte lisible dans la carte ; ne pas rendre toute la carte cliquable en plus du bouton. À l'ouverture, conserver le focus sur le bouton et insérer le contenu immédiatement après lui dans l'ordre de lecture. |
| Moyenne | `EXPERIENCE.md` — State Patterns / résultat périmé, Component Patterns / Status message | Plusieurs échanges peuvent devenir périmés lors d'une modification du modèle ou des paramètres. Une annonce `role="status"` sur chaque carte et sur le bilan produirait des annonces répétitives. Annoncer une seule fois le nombre de résultats à recalculer ; conserver l'état textuel local dans chaque carte et le bilan, sans ancienne valeur active. Associer l'état au bouton de recalcul par `aria-describedby` si nécessaire. Après un calcul, annoncer une phrase courte puis laisser les détails parcourables normalement. |
| Moyenne | `EXPERIENCE.md` — Affichage des quantités, Summary panel | Les unités adaptées aident la lecture visuelle, mais `µgCO₂e`, `m³`, `mWh` et les changements d'unité entre échanges peuvent être difficiles à comprendre ou à entendre. Ajouter une étiquette accessible explicite (« milligrammes de dioxyde de carbone équivalent », « millilitres d'eau »), une aide courte « Les unités changent selon la valeur » et une formulation cohérente pour zéro et « inférieur à ». Définir en mots le risque de sécheresse et son échelle dans le bilan. |
| Moyenne | `DESIGN.md` — Typography, Layout & Spacing ; maquette `.working/palettes-guide-calme.html` | Le document demande un zoom à 200 %, mais ne précise pas la redistribution à une largeur de 320 px ni à 400 % de zoom. Les textes de 9 à 13 px de l'exploration et l'URL ellipsée sont des placeholders de maquette : la version produit doit utiliser les tailles définies dans `DESIGN.md`, permettre l'agrandissement du texte et afficher l'URL complète au focus ou dans le dialogue de consentement. |

## Critères de vérification pour les prochaines maquettes et l'implémentation

- Parcourir les deux voies depuis l'accueil au clavier et au lecteur d'écran, y compris import refusé, confirmation de remplacement, édition et suppression d'un échange.
- Tester à 320 px de largeur effective et à 200 % puis 400 % de zoom, avec taille de texte augmentée et clavier mobile affiché.
- Vérifier les contrastes de chaque état réel (repos, focus, désactivé, erreur), les annonces de calcul et de péremption, ainsi que l'énoncé vocal des unités.

Les spécifications fixent déjà un bon socle : noms et états des contrôles, retour du focus après suppression, absence d'actions au survol, statut textuel, consentement avant réseau et réduction des animations. Les points ci-dessus rendent ces règles assez précises pour être vérifiées pendant la réalisation.
